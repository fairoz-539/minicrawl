# Code of Conduct

This project follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.

In short: be respectful, welcoming and constructive. Harassment, personal attacks, discriminatory language, and publishing others' private information are not tolerated, in issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer, [@fairoz-539](https://github.com/fairoz-539). Use the repository's private reporting (**Security → Report a vulnerability**, and mention it is a conduct report), or contact them through their GitHub profile. All reports are reviewed promptly and kept confidential.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this Code of Conduct. They may also temporarily or permanently ban contributors, as described in the Contributor Covenant's enforcement guidelines.
